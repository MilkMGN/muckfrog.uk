Welcome to the digital monument to one person's questionable life choices. This is a dedicated website celebrating (roasting) the legendary **muck_frog**.

## 📖 About This Project

This repository contains a fun, interactive website that lovingly roasts your friend muck_frog. It's a tribute to their unique charm, questionable decisions, and the absolute comedy gold they provide on a daily basis.

- 🎨 **Dark Green & Yellow Aesthetic** - A striking color scheme that's easy on the eyes while being impossible to ignore

- 📱 **Fully Responsive** - Works seamlessly on desktop, tablet, and mobile devices

## 🛠️ Customization

### Change the Roasts
Open `index.html` and find the roast sections:
```html
<section class="roast-box">
    <h2>Section Title</h2>
    <p>Your roast here!</p>
</section>
```

### Update the Facts List
Modify the bullet points in the "Factual Roast" section to add more "facts" about muck_frog:
```html
<li>Your fact here</li>
```

### Adjust Colors
The color scheme uses:
- Dark Green: `#1a3a1a` (backgrounds)
- Light Green: `#90EE90` (accents)
- Gold/Yellow: `#FFD700` (primary text & highlights)

Find the `:root` or inline `style` tags to customize.

### Change the Image
Simply replace `media/muck.png` with another image and the website will automatically display it.

## 🌐 Deployment

### GitHub Pages
1. Push this repo to GitHub
2. Go to Settings → Pages
3. Set the source to `main` branch
4. Your site will be live at `https://yourusername.github.io/muckfrog.uk`

### Other Hosting
- Upload `index.html` and `media/` folder to any web hosting service
- Works with static file hosts like Netlify, Vercel, or Surge
